# King's Field II — Linux / WebAssembly source port (bootstrap)

A native port of the original Japanese King's Field II (SLPS-00069), built from
the reconstructed sources. Supply your own disc image; game data is not bundled.

This branch is at its first milestones: the original PSX, OPEN, GAME and END
programs compile natively as C++ and run in one executable. The title screen,
the first map and movement render through the GLES3 renderer adapted from the
King's Field port. Sound, movies, near-plane clipping and the per-region map
code modules are not implemented yet; see [port notes](docs/port-notes.md).

## Branches

```text
              master
                 |
     +-----------+-----------+
     |                       |
     v                       v
  source                  classic
     |
     v
   port (you are here)
```

| Branch | Purpose |
| --- | --- |
| `master` | Reconstruction and matching |
| `source` | C++ PS1 build, generated by `kf clean` |
| `classic` | C PS1 build |
| `port` | Linux and browser port |

The `port` branch starts from a generated `source` snapshot and owns every
platform change. Nothing here is pushed back into `source` or `master`; after a
regeneration, rebase the port onto the new `source` root commit.

## Run on Linux

On x86_64 Linux with Nix flakes enabled:

```sh
KF_DISC="/path/to/King's Field II (Japan).cue" nix run .
```

The disc may be the original single-track BIN/CUE or a 2048-byte ISO image.
Saves are memory-card files in the per-user data directory, or in
`--saves DIRECTORY`.

The executable is currently built for i686: the original sources and their
layout checks assume 32-bit pointers. It runs on x86_64 Linux with 32-bit
graphics drivers (on NixOS, `hardware.graphics.enable32Bit = true`).

## Controls

The bring-up input layer exposes a PlayStation pad directly; gameplay-aware
bindings follow in the input milestone.

| PlayStation | Keyboard |
| --- | --- |
| D-pad | Arrow keys or WASD |
| Triangle / Circle / Cross / Square | I / L / K (or Space) / J |
| L1 / R1 | Q / E |
| L2 / R2 | 1 / 3 |
| Start / Select | Enter / Backspace |

Gamepads use their usual layout.

## Build from source

```sh
nix develop
cmake --preset linux
cmake --build --preset linux
build/linux/kings-field-2 --disc "/path/to/King's Field II (Japan).cue"
```

Diagnostics are enabled with environment variables:

| Variable | Effect |
| --- | --- |
| `KF_CAPTURE=DIR` | Write every sixtieth displayed frame as a PPM image |
| `KF_PAD_SCRIPT=FRAME:MASK,...` | Hold hexadecimal pad masks from vertical-blank counts |
| `KF_TRACE=1` | Log pad and input events |
| `KF_WATCHDOG=SECONDS` | Print a backtrace and exit after the given time |

`SDL_VIDEO_DRIVER=offscreen` runs without a window.
